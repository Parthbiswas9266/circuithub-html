# CircuitHub Technologies

A multi-page electronics e-commerce website built as my first HTML project.

CircuitHub Technologies is a fictional electronics company created for practicing and demonstrating fundamental HTML skills.

## 🌐 Live Website

https://parthbiswas9266.github.io/circuithub-html/

## 📄 Pages

The website currently contains:

- **Home** - Introduction, featured products, categories, and company information
- **Products** - Electronics product catalogue with specifications
- **Product Details** - Detailed information about the ESP32-S3 Development Board
- **About Us** - Company information, mission, vision, values, and team
- **Contact** - Contact information and customer enquiry form

## 🛠️ Technologies

- HTML5

No CSS or JavaScript was used in the initial version of this project.

## 📚 HTML Concepts Practiced

This project was built to practice:

- HTML document structure
- Headings and paragraphs
- Hyperlinks and navigation
- Lists
- Tables
- Forms
- Input fields
- Select menus
- Checkboxes
- Buttons
- Header and footer structure
- Basic semantic HTML
- Page-to-page navigation

## 🎯 Project Objective

The objective of this project was to build a complete multi-page website using HTML alone and gain practical experience with structuring real-world web content.

Rather than following a small isolated HTML exercise, the project was built as a complete fictional electronics store with multiple pages and interconnected content.
